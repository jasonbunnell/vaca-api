# Host Pricing
## Description
This document is to outline the pricing and features for 3 different tiers of service for hosts.  Boost and Pro have a Launch Price, where we will offer discounts during the initial launch of the product, timing to be determined later.  The Pro plan has a one time price for a lifetime of service.

## Free Listing
### Price
- Standard Price - Free
### Features
- Property profile page
- Photos (up to 15)
- Description
- Amenities list
- Lake & city search visibility

## Boost
### Price 
- Launch Price - $100/year and renews at Standard Price 
- Standard Price - $150/year.
- No lifetime option
### Features
- Property profile page
- Photos (up to 30)
- Host contact info displayed.  Host email and phone number shown.
- Links to AirBNB and VRBO property profile pages on Property Profile page.
- Rate range displayed

## Pro
### Price
- Launch Price - $200/year
- Launch Price - $600 one time to provide this tier of service forever.
- Standard Price - $300/year
### Features
- Property profile page
- Photos (up to 60)
- Direct booking with OwnerRez integration
- Calendar availability with OwnerRez integration
- Dynamic pricing displayed
- Profile prioritized in results and map search
